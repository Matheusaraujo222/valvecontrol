# ValveControl

Sistema web desenvolvido para controle e acompanhamento de válvulas industriais.

O projeto permite registrar, consultar e acompanhar informações relacionadas à recuperação, sucata e destino das válvulas.

## Tecnologias

* HTML
* CSS
* JavaScript
* PHP
* MySQL

## Demonstração

🌐 **Sistema disponível online:**
https://valvecontrol.wuaze.com/

> **Observação:** A versão online utiliza dados fictícios e uma base de dados independente, criada exclusivamente para demonstração do projeto.

## Funcionalidades

* Cadastro de lançamentos
* Histórico de registros
* Edição e exclusão de registros
* Controle de válvulas em recuperação
* Controle de válvulas recuperadas
* Controle de sucatas
* Relatórios
* Controle de destino MAO/POV

## Objetivo

O ValveControl foi desenvolvido como um sistema web para facilitar o registro e o acompanhamento de informações relacionadas ao controle de válvulas industriais, centralizando os dados em uma interface simples e organizada.
